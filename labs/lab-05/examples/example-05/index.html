Lit: reflect, tipos y ciclo de vida

1 · reflect: true — sincronía propiedad → atributo

Sin reflect, cambiar una propiedad desde JS no actualiza el atributo HTML. Con reflect: true, el atributo se sincroniza automáticamente, lo que permite usar selectores CSS como :host([active]) o :host([variant="danger"]).

2 · Tipos de propiedades: conversión automática de atributos

Lit convierte los atributos HTML (siempre strings) al tipo declarado en static properties. El tipo Boolean tiene un comportamiento especial: la presencia del atributo vale true, independientemente de su valor.

3 · Ciclo de vida: firstUpdated() y updated()

firstUpdated() dispara una sola vez tras el primer render: es el momento correcto para obtener referencias al DOM renderizado. updated(changedProperties) dispara tras cada re-render y recibe un Map con los valores anteriores de las propiedades que cambiaron.
