Introducción a Lit

1 · El mismo componente: Vanilla vs Lit

Ambos contadores tienen el mismo comportamiento. Lit no cambia lo que hace el navegador: reduce el código necesario para decírselo. El diferencial clave: con Lit, this.count++ re-renderiza el componente automáticamente. Con vanilla, hay que actualizar el DOM a mano.

2 · Propiedades reactivas: static properties

Declarar una propiedad en static properties la convierte en reactiva: cuando su valor cambia, Lit re-renderiza solo las partes del template que la usan. No hace falta tocar el DOM.

3 · El template html``: los cuatro tipos de binding

html`` acepta cuatro sintaxis de binding: ${expresión} para valores, @evento para listeners, .propiedad para propiedades DOM y ?atributo para booleanos.
